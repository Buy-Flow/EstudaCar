# EstudaCar — Quiz de veículos

Site estático em HTML, CSS e JavaScript. Não precisa de servidor nem de instalação.

## Publicar com GitHub Pages
1. Abra Settings no repositório.
2. Entre em Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Escolha a branch main e a pasta /(root), depois clique Save.
5. Aguarde a publicação. O endereço costuma ser https://buy-flow.github.io/EstudaCar/.

## Conteúdo
- Catálogo com fichas técnicas e argumentos de venda.
- Quiz de identificação com quatro alternativas.
- Prova de 10 questões e pontuação.

## Importante
As fotos vêm de sites externos e podem representar outro ano/versão. Os valores de FIPE são referências anteriores e precisam ser conferidos pela versão exata, código FIPE e mês de referência antes de serem usados numa venda. Confirme os dados do veículo no CRLV/VIN, manual e inspeção física.
